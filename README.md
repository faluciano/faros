# Faros (WIP)

Web app to track visited lighthouses around the world with a map to display visited points

# Functionality

- [x] Lighthouse map
- [x] Login/Register
- [x] Visited Lighthouse map
- [x] Friends
- [x] Combined friend/personal map
- [x] Saved Lighthouses
- [ ] Lighthouse visit upload

# Stack

- Go (Backend)
- React (Frontend)
- Clerk (Auth)
- Turso with embedded replica (DB)
- Pigeon-Maps (Maps)
